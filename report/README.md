# Report

Save the Power BI file here:

- **Recommended:** `File → Save as → Power BI project (.pbip)` → `Financial Performance Dashboard.pbip`. The semantic model (TMDL) and report definition are plain text, so every measure change shows up as a readable diff on GitHub.
- Or a single `Financial Performance Dashboard.pbix`. Fine for a portfolio, but GitHub can only show it as a binary.

Local cache files (`.pbi/localSettings.json`, `.pbi/cache.abf`) are git-ignored.
